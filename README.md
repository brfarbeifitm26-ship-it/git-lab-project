# Git Lab Project

Навчальний консольний проєкт для лабораторної роботи з Git.

## Структура
- `LabProject.sln` — рішення Visual Studio.
- `LabProject/` — файли консольного застосунку.

## Використання
Відкрийте `LabProject.sln` у Visual Studio.

## Розробка
Поточні зміни гілки розробки виконуються у `develop`.
